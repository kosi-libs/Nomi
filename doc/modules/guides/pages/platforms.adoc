= Supported platforms

Resources, services and the client run on every platform below, whereas the server is JVM-only.

`nomi-runtime-shared` and `nomi-runtime-client` are Kotlin Multiplatform libraries targeting:

* *JVM*
* *iOS* — `iosArm64`, `iosSimulatorArm64`, `iosX64`
* *watchOS* — `watchosArm32`, `watchosArm64`, `watchosDeviceArm64`, `watchosSimulatorArm64`
* *tvOS* — `tvosArm64`, `tvosSimulatorArm64`
* *macOS* — `macosArm64`
* *Android Native* — `androidNativeArm32`, `androidNativeArm64`, `androidNativeX64`, `androidNativeX86`
* *Linux* — `linuxX64`, `linuxArm64`
* *Windows* — `mingwX64`
* *JS* — browser, Node.js
* *Wasm/JS* — browser, Node.js

`macosX64` (Intel macOS) is deliberately not a target: Kotlin deprecated it in 2.3.20 and will remove it.
`iosX64` — the Intel iOS _simulator_, not Intel hardware — is kept because it is still a supported target.

`nomi-runtime-server` is JVM-only, built on ktor-server.
